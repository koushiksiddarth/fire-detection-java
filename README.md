# Fire Detection Using Java

#Live Demo 
https://fire-detection-java-live.onrender.com

A Java Spring Boot web application for detecting fire from uploaded images.

## Technologies
- Java
- Spring Boot
- HTML
- CSS
- Maven

## Features
- Upload an image
- Analyze the image
- Detect possible fire
- Display the detection result

## How to Run

1. Install Java 17 or later.
2. Open the project in IntelliJ IDEA or Eclipse.
3. Run `FireDetectionApplication.java`.
4. Open:
   http://localhost:8080

## Project Structure

src/main/java/com/fire/
- controller/
- service/
- FireDetectionApplication.java

src/main/resources/
